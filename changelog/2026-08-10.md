The [Identity Layer chapter](/book/chapter-04/04-identity-layer) is now backed
by machine-checked proofs in Lean 4, delivered as a stacked chain of five pull
requests (#195-#199, stack #200, commit `f56efa4` on `main`). Epic #69 and
sub-issues #190-#194 closed.

## Updates

- **Identity tier mutability.** `IdentityTiers.lean` proves the four-tier
  mutation rules (Sec 3) — including the symmetry asymmetry of immutable and
  reversible tiers.
- **Genesis bootstrapping.** `IdentityGenesis.lean` proves the 3-of-5 multisig
  genesis sequence (Sec 4): signatures collect monotonically, the deadline
  releases entropy, and the nonce changes only on success.
- **Sandboxed isolation buffer.** `IdentityBuffer.lean` proves the buffer
  protocol of Sec 5.2: ontology extensions are heap-sandboxed and only a
  fully-cleared extension (monitor, validation, and keyholder audit) enters
  the core buffer.
- **Runtime integrity hashes.** `IdentityHashes.lean` proves that tampering
  with any implementation changes the deterministic chain root, that the TEE
  recomputes hashes independently of the stored binding, and that
  `verify_runtime` accepts exactly the matching implementation
  (Sec 2.1 and 6.1).
- **Coherence threshold guard.** `IdentityCoherence.lean` proves that
  accepted actions keep identity coherence above the threshold and that
  below-threshold actions are rejected without mutating identity state
  (Sec 6.1).
- **Documentation pipeline back on GitHub Pages.** The docs build returns to
  the free mkdocs + GitHub Pages pipeline (restored `docs.yml` workflow); the
  paid Mintlify setup was removed. New page: [Formal Verification
  (Lean)](/book/formal-verification-lean) inventorying every proof module.
